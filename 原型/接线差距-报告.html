Wiring Gap · 接线差距 · 2026-11-08

交互版离「直接替换博客」还差什么

对照线上站构建产物（public/）逐页核对后的结论：开工前原型只有 5/12 的页面类型；本轮把缺口全部补进原型——12 条路由、三语同页切换、文章页全部组件。页面形态层面已可 1:1 映射，剩余差距都在 Hugo 构建才能产出的一层。

面板一 · 页面类型：5 → 12

路由（原型 = 站点）本轮前本轮后
#/ · #/posts · #/posts/:slug · #/search · #/about已有三语化 + 契约对齐
#/archives（归档台账）缺新增
#/guestbook（留言板 = giscus 本体）缺新增 · 三语真实引导语
#/tags · #/tags/:term缺（标签链到搜索）真实 term 路由 · 18 词条
#/categories · #/categories/:term缺新增 · 文章分类改指 term 页
未知路径 → 404 视图回落首页404 + 三出口 + 最近 3 篇
#/ja/… · #/en/…（语言前缀路由）假菜单外链全 chrome + 真实机翻译文

ja/en 数据不是占位：10 篇标题摘要、关于页、留言板、zz-s03 全文，全部取自仓库构建产物（即翻译流水线的真实输出）；无译文的瞬时窗口设计为「译文准备中」状态。

面板二 · 文章页组件补齐

  • 灯箱：Esc/外点关闭、滚动锁、焦点回归（88dvh）
  • 代码复制：每块代码一枚按钮 + 2s 状态反馈
  • #wide / #full 图文破格：与站点 kg-width 同公式，1440 实测 wide=1200px、列 680px，≤1248px 塌回
  • 视频门面（bilibili_bvid 形态）+ 自托管音频（可播放演示音）
  • 脚注：sup 引用 + 注释节 + 回跳
  • 分享组：触屏走系统分享并隐藏 X/Telegram；桌面 X/TG + 复制（与站点行为一致）
  • 评论壳：giscus 的位置/间距/键盘序照站点预留，不加载第三方脚本

面板三 · 取舍（一切以调研为准）

分歧调研证据选边

TOC 侧别既有 15 站调研：唯一有 TOC 的博客在右，文档站全在右右侧（站点左侧浮层建议跟进迁移）
评论形态样本中评论近缺席；本站已部署 giscus保留 giscus（站点事实优先）

  • head 契约：canonical / og / JSON-LD / hreflang+x-default / feed 发现 / OpenSearch link
  • giscus 真脚本与主题跟随（comments.html 已有，换壳即可）

  • RSS / sitemap / llms.txt / robots / 封面 srcset：纯构建产物
  • feature-check 增量断言；CMS 零新增字段（现有 front matter 足够表达全部形态）
