02逐条判断

每条都给「为什么是这个值」，以及反方在哪。

01断点：860 → 768

768 是样本最高频断点，也是 Tailwind md 与 Bootstrap 的约定值，等于「所有用现成框架的人都停在这里」。640 偏早（本站导航只有 2 项，640 会让平板用户白点一次汉堡）；860/866 只有两家，且那两家是 6 个文字链接才需要换排。你原来的 860 还让 iPad 竖屏（820/834）掉进手机布局，这是实打实的损失。

02归档：不设独立导航项

「归档」在 15 家的导航里出现 0 次；有独立归档页的只有 2 家，其中阮一峰那页本质是「最近 20 篇 + 18 个分类」，jim-nielsen 是 812 篇的 List/Calendar 双视图——那是十年积累才需要的工具。你 10 来篇、文章页已经按年分组，独立归档页的信息增量接近零。

反方也成立：中文 Hexo/WordPress 语系读者对「归档」有肌肉记忆。折中办法是保留 URL 但降级——站点 /archives/ 建议 301 到 /posts/，既不丢外链，也不占导航位。

03目录：留右侧

弱证据，但是唯一的方向性证据：样本里唯一有 TOC 的博客在右侧，左侧 0 家；MDN、Starlight 这些文档站也把 TOC 固定在右栏（左栏留给站点导航）。你现在站点是左侧，属于少数派。改不改都不影响阅读，但「两套路径」不该长期并存——建议站点后续跟到右侧。

04小字：硬下限 12px

样本中位 12.8px；8px 全样本只出现一次（作者简介），10px 只出现一次（侧栏深层列表）。也就是说，把 8px 用在品牌副标、10px 用在标签计数，在真实博客里没有先例。已把 .year-label small 11→12、标签计数 10→12、.toc-float-title 10.5→12，并把所有 11.5 并入 12。

.brand-en（DEUX）升到 10px 并明确豁免：它是标识副标而不是阅读文本，与正文下限是两套规则。

05阶梯：文字档 12/14/16/18/22 + 展示档 28/36/44/52/60

手写站点中位 7 级，你原来 30 个值里有 11.5 / 14.5 / 17.5 三个半像素值和 24–58 之间 13 个近邻阶（24/25/26/29/31/34/36/38/40/44/46/48/50/58），相邻差常低于 5%，肉眼分辨不出，只增加维护成本。现在文字档 5 级、展示档 5 级，标题仍用 clamp 流式，档位只做端点。

06衬线：补 Noto Serif SC / JP

不是审美判断，是实测到的 bug：旧栈写的是 Noto Serif CJK SC，而 Windows 上装的名字是 Noto Serif SC，名字对不上直接跳过，标题全部落到 SimSun。用 Chrome 的 getPlatformFontsForNode 取真实字体：改前 .hero-title = SimSun，补名后 = Noto Serif SC。零下载、纯本地字体，装的机器自动升级，没装的仍落 SimSun（不比现在差）。

07hreflang：zh 而不是 zh-CN

线上实测：curl 三语列表页，head 输出的是 hreflang=zh（Hugo 语言码），而 <html lang> 是 zh-CN。原型写成 zh-CN 会导致和站点自己的集群对不上。已改 hreflang，lang 保留 zh-CN。

08手机头部 4 个图标：保留（明知越界）

样本众数是 0 个，多数站点 1–3 个，4 个只有一家。但那些站点没有三语切换——你的语言入口是内容可达性，不是装饰。实测 320px 下：品牌 70px + 四个 44px 图标 + 间距 = 294px，仍余 26px，没有挤压。所以这次让可达性优先于启发式，并在文档里记成「已知例外」，而不是假装它符合惯例。

09进度条 / 阅读时长：保留

15 家里 0 家有阅读进度条、0 家显示阅读时长。这两个是「超出惯例的增强」，不是错误——站点已经上线并写进设计定案，本轮不动。真要减负，它俩才是第一个该砍的，而不是语言入口。

03局限：什么会推翻这些判断

样本。15 家偏英文技术/写作博客，中文只 3 家；「右侧 TOC」只有 1 个博客样本 + 文档站类推，属于弱证据。

方法。断点与字号取自 CSS 原文，不是渲染快照；手机图标数是按 ≤480px 媒体查询推导，未逐站截图。zhangxinxu 用 Chrome UA 返回 403，换 Safari UA 才拿到。

字体。结论依赖本机装了 Noto Serif SC。没装的 Windows 仍落 SimSun——补名不会让它更差，但也修不好没装字体的机器；真要全平台一致只能上自托管切片，那是另一个成本量级。

04已落地

断点 860→768（含 JS resize 门控）；字号阶梯收敛（30 值 → 文字 5 档 + 展示 5 档，正文统一 18）；小字下限 12（品牌副标 10 豁免）；display 栈补 Noto Serif SC/JP；hreflang 改 zh。全部在真实 Chrome 复验：768px 时导航收起、769px 时展开，320/390/768/1440 零横向溢出，标题平台字体已从 SimSun 变为 Noto Serif SC。

站点侧只有一条待跟进：/archives/ 301 到 /posts/；以及目录侧别要不要跟到右侧——这两条要动 Hugo 模板与 netlify.toml，不在这次原型范围内。
