## 2. 分层落点（按 AGENTS.md 功能分层）

### Level 1（front matter）——零工作
现有字段（cover/description/tags/categories/lastmod/weight/aliases…）足以表达原型全部形态，`.pages.yml` 不动。

### Level 2（站点层 CSS/JS）——工作量主体

| 原型资产 | 站点落点 | 说明 |
|---|---|---|
| 内联 CSS（字阶/间距/胶囊语言/编辑部排版） | `assets/css/extended/` 重整：`typography.css` 改造 + 新增 `home.css`（编辑部首页）、`list.css`（文字目录+分页器）、`chrome.css`（头部/页脚） | 保留 `--u` 双断点约定的**换轨决策**：原型用 `--sp-1…9`（4/8/12/16/28/40/48/64/96）+ `--sp-section/head/tail`。**方案：以 `--sp-*` 全站换轨，`--u` 标尺退役**（原型实测过的标尺优先；feature-check「间距单位(--u双断点)」断言同步改写） |
| 黄金字阶 | `typography.css` 保留流式标题梯子与 φ 节奏 | 原型与之兼容（排版体系一脉相承），只调 display 衬线位 |
| `main.js.txt`（原型 JS） | 重写进 `assets/js/site.js`：**删 hash 路由与 inline JSON 加载**，保留交互件：头部动作组、语言面板（真实 hreflang 数据源不变）、搜索回填/快捷键、灯箱、回顶、代码复制、进度条、原生分享、TOC 浮层、摘要折叠 | feature 序号全部保留语义，feature-check 的 JS 字面量断言随之改写 |
| Feather 图标 | 沿用现 ui.css 五槽一体形态 | 已是原型同款，改动极小 |

### Level 3（模板覆盖）——克制清单（逐个列出，weekly re-diff 负担在此）

| 模板 | 来源 | 动作 |
|---|---|---|
| `layouts/_default/list.html` | 新覆盖 | 年份分组行式列表 + 分页器（`pagerSize=10`，现语料不触发，机制先就位） |
| `layouts/_default/archives.html` | 已有覆盖则改、无则覆盖 | 紧凑年份台账（完整索引，不分页） |
| `layouts/_default/terms.html` / `taxonomy.html` | 覆盖 | 词条/分类索引 + term 页（现 tag-entry 形态退役） |
| `layouts/_default/single.html` | **尽量不覆盖** | 文章页骨架靠现有 order/margin 补偿 + extend_head 注入维持；仅当 TOC 右浮必须改 DOM 时再评估（优先纯 CSS：`details.toc` fixed 定位改 right 即可，**不动模板**） |
| `layouts/404.html` | 覆盖 | 404 + 一句话 + 三出口 + 最近 3 篇 |
| `layouts/index.html`（profileMode） | 覆盖或 type 分支 | 编辑部式 hero + 近作 + 按年份浏览入口 |
| `layouts/_partials/structured/`、`comments.html`、`extend_head.html` | 已有 | 换壳映射评论壳样式；head 契约全部保留不动 |

**覆盖数量红线**：新增覆盖 ≤6 个文件；每个新覆盖在 feature-check 里各有一条守卫断言，weekly PR 碰同名文件按 AGENTS.md 人工 review。

## 3. 施工阶段（每阶段可独立构建、独立回退）

**Phase 0｜准备**（0.5 天）
- 开分支 `redesign/proto-wiring`；记录现站 public 基线（`hugo` 全量构建 + 6 视口截图存 `.zcode/audit/baseline/`）
- §1 三项签认

**Phase 1｜设计令牌与 chrome**（1 天）
- `--sp-*` 间距体系、衬线 display 字体层进 extended CSS；头部动作组/语言面板/页脚按原型换肤
- 验收：头部五图标形态不回退、语言同页切换与汉堡/globe 双态门控全部保持

**Phase 2｜首页**（1 天）
- profileMode → 编辑部式 hero + 近作 3 篇 + 目录入口（指向 archives）
- 验收：三语首页、社交图标、profileMode 搜索按钮保留

**Phase 3｜列表系统**（1.5 天）⚠️ 需签认项 #1 落地处
- `/posts/` 文字目录 + 分页器；archives 台账；tags/categories 索引与 term 页
- 拆除 Casper 堆叠卡 CSS（cover.css 卡片段）与「列表堆叠卡」断言，换「列表文字目录」断言
- 验收：pagerSize=10 分页、筛选进 URL 的站点等价物（`/categories/日常/` 等 term 页即筛选）、无 `:not(.tag-entry)` 残留死规则

**Phase 4｜文章页**（1.5 天）
- TOC 浮层改右侧（纯 CSS）；封面/目录/媒体/标签分享行/paginav/相关文章/评论壳间距对齐原型
- 保留：图文三档破格、封面 srcset（720px/100vw）、giscus 主题跟随、相关文章焦点归位
- 验收：焦点序、margin 补偿边界、灯箱滚动锁回归

**Phase 5｜搜索/404/关于/留言板**（1 天）
- 搜索页视觉体系对齐原型（胶囊语言/聚合标题），fastsearch 逻辑不动；404 新页；关于/留言板微调
- 验收：Ctrl+K/Alt+/?q= 回填/不自动聚焦等既有断言全绿

**Phase 6｜feature-check 增量 + 全量回归 + 上线**（1 天）
- 新增断言（§4）；`node scripts/translate.mjs --self-test` 与翻译流水线不接触（本方案不动 content）
- 本地 6 视口对照原型复跑 `final-round*.sh` 移植版 → Netlify deploy preview → `curl deux.top` 抽查 → 合并 main
- 上线后观察一个 weekly PR 周期的 re-diff 负担

## 4. feature-check 增量断言清单（63 项基础上）

| 新断言 | 守卫点 |

同步**删除/改写**因形态退役而失效的断言：「列表堆叠卡」「分类元信息行」的卡片侧、「间距单位(--u)」。预期总量 63 → ~66。
