> 本記事はAIによる自動翻訳です。表現が不自然な場合は[中文の原文](/zh/posts/cf-auto-translate/)をご参照ください。

このブログは三か国語（簡体中国語／日本語／英語）で構成されています。中国語の記事を push すると、数分以内に日本語版と英語版が自動生成され、自動デプロイされます。この記事では、このパイプラインの最終的な形を詳しく紹介します。

## 全体のアーキテクチャ

```
中国語の記事を書く → GitHub Actions（translate-content）
  → AI Gateway を経由して Cloudflare Workers AI を呼び出す
  → Hugo で構築と検証（不具合のある front matter を防ぐ）
  → bot が git に書き戻す
    → Netlify が自動デプロイし、日本語・英語版が公開
```

4つの設計原則：

- **製品を git に送る**：翻訳文はレビュー可能、ロールバック可能、人間が引き継げる。Netlify の構築で得られるのは常に完成した Markdown である
- **訪問者側は完全に静的**：API 認証情報は GitHub Actions のみに存在し、フロントエンドにはシークレットも追加リクエストもサードパーティスクリプトも一切ない
- **すべてのリクエストは AI Gateway を通る**：各リクエストのトークン、ドルコスト、処理時間はログで確認可能。同じ内容を再実行するとキャッシュがヒットし、コストはかからない
- **一部の失敗が全体を妨げない**：ある言語の翻訳に失敗しても、他の言語の公開には影響しない

## モデルと呼び出し方法

モデルには `@cf/qwen/qwen3-30b-a3b-fp8` を使用しています（無料プランで利用可能、MoE アーキテクチャのアクティブパラメータは 3B で、料金プランの最低ランク）、思考モードはオフにしています。翻訳タスクには推論は不要で、クォータを節約し、より安定します。

毎回の翻訳は2つの呼び出しに分割されます：

| 呼び出し | 内容 | 出力制約 |
|---|---|---|
| フィールド | タイトル／要約／分類／タグ／カバーテキスト | JSON Schema で厳密に制約され、形式が不正な場合は API でブロックされる |
| 本文 | Markdown 全文 | プレーンテキスト出力、Markdown の構造を保証 |

本文の翻訳には**構造 QA モンガ**があります。翻訳文と原文を比較し、リンクや見出し、コードブロックの数を確認します。不足している場合は、原文の URL リストをもとに機械的に修復（リンクを `[文字](URL)` の形式に戻す）します。修復ができない場合は再翻訳します。出力の切り捨てガード（max_tokens の上限に達すると予算を追加して再試行）、180秒のタイムアウト、429/5xx の指数バックオフを組み合わせることで、1回の実行で失敗する確率は非常に低くなります。

## インクリメンタル：2つのハッシュ

各翻訳ファイルの front matter には2つのマークが含まれます：

```toml
source_hash = '…'        # 本文の sha256（プロンプトバージョン番号とモデル名を含む）
source_fields_hash = '…' # フィールドセットの sha256
```

- 中国語の**本文**が変更された → 本文のみを再翻訳、フィールドは元の翻訳を引き継ぐ
- **要約／タグ**のみが変更された → フィールドのみを再翻訳、本文は変更しない
- モデルを変更またはプロンプトをアップグレードした → バージョン番号が変化 → 全体を再翻訳
- 何も変更がない → 0回の API 呼び出し（毎週日曜日の03:17に定期的にチェックし、全体をスキャンしてバックアップ）

## SEO 要約も管理対象

中国語の記事に要約がなかった（CMS で空欄）場合でも問題ありません。パイプラインは70〜160文字の要約を生成し、front matter に書き戻します。三か国語のフィールドの翻訳はこれに基づいて行われます。**中国語・日本語・英語の要約は常に同じソースから生成されます**。その後、CMS で要約を編集して保存すると、三か国語が自動的に更新されます。

## 人間の判断は常に一票

- CMS の翻訳項目で「翻訳をロック」にチェック → この翻訳は人間の作業とみなされる：上書きや削除はされず、中国語の元記事が更新されても同期されない
- CMS の中国語項目で「翻訳しない」にチェック → この記事はパイプラインから除外される
- 校正済みの機械翻訳は、中国語のソースの対応部分が変更されなければ再翻訳されない（CMS で保存してもハッシュマーカーは破損しない）
- ライフサイクルの同期：中国語の記事が削除されると、翻訳も自動的に削除される。中国語の記事が下書きに変更されると、翻訳も自動的に非表示になる

## コスト

無料プランでは1日10,000ネイロンが利用可能。実測では、全文の三か国語翻訳で約100ネイロン、要約のみの翻訳で約5ネイロン。日常的なインクリメンタルは上限に達することはない。AI Gateway のログでは、各リクエストのトークン、ドルコスト、処理時間を直接確認可能。
