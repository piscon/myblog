> 本記事はAIによる自動翻訳です。表現が不自然な場合は[中文の原文](/zh/posts/cf-auto-translate/)をご参照ください。

このブログは三か国語（簡体中国語／日本語／英語）で書かれています。以前は各言語バージョンを手動で作成していましたが、記事が増えると対応が追いつかなくなりました。そのため、自動翻訳のフローを構築しました。中国語の記事をプッシュすると、数分以内に日本語と英語版が自動生成され、自動デプロイされます。

## 全体構成

```
中国語の記事をプッシュ
  → GitHub Actions（translate-content）
    → Cloudflare Workers AI を呼び出して翻訳
      → 翻訳結果をgitに書き戻す
        → Netlify が自動的にビルド・デプロイ
```

いくつかの重要な決定事項：

- **翻訳結果をgitに保存**し、Netlifyのビルド時に一時的に生成しない。翻訳結果はレビュー・ロールバック・手動修正が可能で、Netlifyのビルドは純粋な成果物のみを取得する
- **Cloudflare Workers AI の無料枠を使用**（毎日10,000 neurons）。個人ブログの翻訳量はこれで十分
- **訪問者側は完全に静的**：API keyはGitHub Actionsのみにあり、フロントエンドには秘密鍵や追加リクエストが一切なく、第三者スクリプトも読み込まれない

## モデル選定

Workers AI の無料プランにはモデルのホワイトリストがあり、すべてのモデルが使用できるわけではありません。いくつかのモデルをテストしました：

- GLM、DeepSeek シリーズ：無料プランでは使用不可（403エラー）、即座に除外
- `llama-3.3-70b`：使用可能だが、純テキストの翻訳では**文の一部が翻訳されない**（一部の中国語の原文が残る）、使用不可
- `qwen3-30b-a3b-fp8`：中国語→日本語の品質が最も良い、最終的にこれを選択

## 最大の落とし穴：Markdown を JSON に詰め込まない

初版では手間を省くために、タイトル、要約、本文を1つのJSONにまとめ、モデルに翻訳して元の形式で返してもらいました。その結果、フィールドはすべて正常でしたが、本文内のリンク構文が破損してしまいました：

```
元のファイルの書き方：      [Hugo](https://gohugo.io)
JSON形式での出力：   Hugo（https://gohugo.io）          ← リンクが死んでしまった、単なるテキストに
純テキスト形式での出力：  [Hugo](https://gohugo.io)          ← 構文が元のまま保持された
```

qwen3 と llama ともにこの問題がある——特定のモデルの問題ではなく、「Markdown を JSON 文字列に含める」この形式自体がモデルにとって不向きで、エスケープレベルが多すぎるためです。

**2段階の呼び出しに変更**：フィールド（タイトル/要約/分類/タグ）は短いテキストで、小規模なJSON呼び出しで問題ない。本文は別途純テキスト呼び出しを行う。これにより、リンク、リスト、コードブロックがすべて元のまま保持されるようになりました。

## インクリメンタル：source_hash

すべての記事をプッシュするたびに再翻訳しないようにする——これは枠を浪費し、さらに深刻なのは、手動で校正した翻訳を上書きしてしまうからです。したがって、各翻訳ファイルの front matter に `source_hash` を保存します：

```toml
lang = 'ja'
title = '（翻訳後のタイトル）'
date = '2025-11-26'
draft = false
source_hash = '4bae5986e7a0…'  # 中国語の元の内容の sha256、ヒントのバージョン番号とモデル名を含む
```

ルール：

- hash が一致 → スキップ、**API呼び出しは0回**
- 中国語の原文が変更された → hash が一致しない → 自動的に再翻訳
- モデルを変更 → hash の中のモデル名が変更 → 全量再翻訳

## 人工保護ルール

- `source_hash` が存在しない翻訳 = 人工で書かれたもの、スクリプトは**絶対に触らない**（上書きも削除もしない）
- 機械翻訳ファイルが人工で校正された後、中国語の原文が変更されなければ、再翻訳されない
- 1つの記事を翻訳したくない：中国語の front matter に `auto_translate = false` を追加
- 中国語のソースが下書きになる → 翻訳ファイルも同期して非表示に；中国語のソースが削除 → 翻訳ファイルが自動的に削除

機械翻訳ファイルの先頭には1行の引用ブロックの宣言があり、元の記事へのリンクが記載されており、読者に中国語の原文を基準としていることを伝えています。
