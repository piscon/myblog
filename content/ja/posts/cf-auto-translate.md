> 本記事はAIによる自動翻訳です。表現が不自然な場合は[中国語の原文](/zh/posts/cf-auto-translate/)をご参照ください。

このブログは3か国語（簡体中国語／日本語／英語）で書かれています。中国語を書いた後、プッシュすると、数分以内に日本語版と英語版が自動生成され、自動デプロイされます。この記事では、このパイプラインの最終的な形を詳しく紹介します。

## 全体のアーキテクチャ

```
写完中文文章 push
  → GitHub Actions（translate-content）
    → 经 AI Gateway 调 Cloudflare Workers AI
    → 产物过 Hugo 构建校验（防坏 front matter 打挂部署）
    → bot 提交回写 git
      → Netlify 自动部署，日/英文版上线
```

4つの設計原則:

- **製品をgitに送る**: 訳文はレビュー可能で、ロールバック可能、人手で引き継ぐことが可能。Netlifyが構築するものは常に完成したMarkdownである
- **訪問者側は完全に静的**: APIの認証情報はGitHub Actionsにのみ存在し、フロントエンドには認証情報が一切なく、追加のリクエストも、サードパーティのスクリプトも一切ない
- **すべてのリクエストはAIゲートウェイを通る**: それぞれのリクエストのトークン、ドルコスト、処理時間はログで確認可能。同じ内容を再実行するとキャッシュがヒットし、コストは一切かからない
- **一部の失敗が全体に影響しない**: ある言語の翻訳に失敗しても、他の言語の公開には影響しない

## モデルと呼び出し方法

`@cf/qwen/qwen3-30b-a3b-fp8`を使用（無料プランでも利用可能。MoEアーキテクチャのアクティベーションパラメータは3Bで、課金プランの最安値）、思考モードをオフにしている—翻訳タスクには推論は不要で、クレジットを節約し、より安定する。

毎回の翻訳は2つの呼び出しに分割される:

| |の内容 | 出力制約  |
|---|---|---|
| フィールド | タイトル / 概要 / 分類 / タグ / カバーテキスト | JSON Schema による強制的な制約、形式が不正な場合は API で直接ブロックされます  |
| 本文 | Markdown 全文 | マークダウン構造を保持した純粋なテキスト出力  |

本文の翻訳には1つの ** 構造 QA ポート ** があります。翻訳文と原文を比較し、インラインリンク、タイトル、コードブロックの数を確認し、短縮されている場合は元のURLリストに基づいて機械的に修復します（破損したリンクを `[文字](URL)` に戻します）。修復ができない場合は再翻訳します。出力の切り捨てガード（max _ tokens の上限に達すると自動的に予算を追加して再試行）、180秒のタイムアウト、429/5xxの指数バックオフを組み合わせることで、1回の実行での失敗範囲は非常に小さくなります。

##  インクリメンタル：2つのハッシュ

各翻訳ファイルの front matter には2つのタグが含まれます：

```toml
source_hash = '…'        # 正文的 sha256（混入提示词版本号与模型名）
source_fields_hash = '…' # 字段集的 sha256
```

-  中国語 ** 本文 ** 変更済み → 本文のみ再翻訳し、フィールドは元の翻訳を引き続き使用します
-  は ** 要約/タグ ** を変更したのみ → フィールドのみ再翻訳、本文は変更しない  
-  モデルの変更やプロンプトのアップグレード → バージョン番号の変化 → 全量再翻訳を行う  
-  何も変更しない → 0 回の API 呼び出し（毎日曜日 03:17 の定時精算はこのように全量スキャンでバックアップしている）  

##  SEO 要約もこれに含まれる  

中国語の記事に要約が書かれていない（CMS で空欄のまま）でも問題ない：パイプラインは 70 - 160 字の要約を front matter に自動生成し、三語フィールドの翻訳はこれを元にしている——** 中・日・英の三語要約は常に同じソースから生成される**。その後、CMS で要約を編集して保存すると、三語は自動的に更新される。  

##  人間の判断は常に一票を持つ  

-  CMS の翻訳項目に ** 「翻訳をロック」** を選択 → この翻訳は人間の原稿とみなされる：上書きされず、削除されず、中国語の原文が更新されても同期されない  
-  CMS の中国語項目に ** 「翻訳しない」** を選択 → この記事はパイプラインから除外される  
-  校正済みの機械翻訳は、中国語ソースの対応部分が変更されなければ再翻訳されない（CMS で保存しても hash マークは破損しない）  
-  ライフサイクルの同期：中国語が削除 → 翻訳が自動的にクリーンアップされる；中国語が下書きに変更 → 翻訳が自動的に非表示になる  

##  コスト  

無料プランでは毎日 10,000 ニューロンが利用可能。実測では、全文の三語翻訳で約 100 ニューロン、要約のみの変更で約 5 ニューロンとなる。日常的な増分ははるかに上限に達しない。AI Gateway のログでは、各リクエストのトークン数、ドルコスト、処理時間が直接確認できる。
