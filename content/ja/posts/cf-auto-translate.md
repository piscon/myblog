> 本記事はAIによる自動翻訳です。表現が不自然な場合は[中国語の原文](/zh/posts/cf-auto-translate/)をご参照ください。

このブログは3か国語（簡体中国語／日本語／英語）で作成されています。中国語を書いた後、プッシュすると、日本語版と英語版は数分で自動生成され、自動的にデプロイされます。この記事では、このパイプラインの最終的な形について詳しく説明します。

## 全体のアーキテクチャ

```
写完中文文章 push
  → GitHub Actions（translate-content）
    → 经 AI Gateway 调 Cloudflare Workers AI
    → 产物过 Hugo 构建校验（防坏 front matter 打挂部署）
    → bot 提交回写 git
      → Netlify 自动部署，日/英文版上线
```

4つの設計原則：

- **成果物をgitに送る**：翻訳は確認可能で、ロールバック可能、人手で引き継ぐことが可能であり、Netlifyが構築するものは常に完成したMarkdownです
- **訪問者側は完全に静的**：APIの認証情報はGitHub Actionsにのみ存在し、フロントエンドには認証情報が一切なく、追加のリクエストも、サードパーティのスクリプトもありません
- **すべてのリクエストはAIゲートウェイを通る**：各リクエストのトークン、ドルコスト、処理時間はログで確認可能です。同じ内容を再実行するとキャッシュがヒットし、コストはかかりません
- **一部の失敗が全体に影響しない**：ある言語の翻訳に失敗しても、他の言語の公開には影響しません

## モデルと呼び出し方法
`@cf/qwen/qwen3-30b-a3b-fp8` これに関する番号は元のまま保持され、位置は変更せず、それぞれ一度だけ出現します。  
中国語はすべて翻訳する必要があります。翻訳結果のみを出力してください。

| 調用 | 内容 | 出力制約 |
|---|---|---|
| 字段 | タイトル / 概要 / 分類 / タグ / カバーテキスト字 | JSON Schema の強制制約、形式が不正な場合は API でブロックされます |
| 正文 | Markdown 全文 | 純テキスト出力、Markdown の構造を保持します |

本文の翻訳には、1つの**構造の QA ドア**があります。翻訳結果と元の文章を比較して行内リンク、タイトル、コードブロックの数を確認し、短縮されたものは元のURLリストを使って機械的に修復します（破損したリンクを`[文字](URL)`に戻します）。修復できなければ再翻訳します。出力の切り捨てガード（max_tokens の上限に達すると予算を追加して再試行）、180秒のタイムアウト、429/5xx の指数バックオフを組み合わせることで、1回の実行での失敗率は非常に小さくなります。

##  インクリメンタル：2つのハッシュ

各翻訳ファイルの front matter には2つのマーカーが含まれます：

```toml
source_hash = '…'        # 正文的 sha256（混入提示词版本号与模型名）
source_fields_hash = '…' # 字段集的 sha256
```

- 中国語**本文**が変更された場合 → 本文のみ再翻訳、フィールドは元の翻訳を引き継ぎます  
- フィールドのみ変更された場合**概要/タグ** → フィールドのみ再翻訳、本文は変更しません  
- モデルの変更やプロンプトのアップグレード → バージョン番号の変化 → 全体を再翻訳します  
- 何も変更されていない場合 → API 呼び出しは0回（毎週日曜日の03:17に定期的に全量スキャンしてバックアップを行っています）

## SEOの概要もこれに含まれます

中国語の記事に概要が書かれていない（CMS で空欄のまま）場合でも問題ありません。パイプラインは70〜160字の概要を生成し、front matter に書き戻します。三語のフィールドの翻訳はこれに基づいて行われます。**中国語・日本語・英語の三語の概要は常に同じソースから生成されます**。その後、CMS で概要を編集して保存すると、三語の翻訳が自動的に更新されます。

## 人間の判断は常に最終的なものです

- CMS の翻訳項目に「翻訳をロック」をチェック → この翻訳は人間の原稿として扱われます：上書きや削除はされず、中国語の元の文章が更新されても同期されません。
- CMS の中国語項目に「翻訳しない」が選択されている場合→本文はリリースフローから除外されます
- 校正済みの機械翻訳は、中国語の元の部分が変更されなければ再翻訳されません（CMS で保存しても hash マークは破損しません）
- ライフサイクルの同期：中国語が削除される→翻訳が自動的にクリーンアップされます；中国語が下書きになる→翻訳が自動的に非表示になります

## コスト

無料プランでは1日で10,000ネイロンが使用可能です。実際の測定では、全文の3言語翻訳で約100ネイロン、要約のみを変更する場合は約5ネイロンです。日常的な増分ははるかに上限に達することはありません。AI Gateway のログでは、各リクエストのトークン数、ドルコスト、処理時間などを直接照会できます。
