> 本記事はAIによる自動翻訳です。表現が不自然な場合は[中文の原文](/zh/posts/cf-auto-translate/)をご参照ください。

このブログは三か国語（簡体中国語／日本語／英語）で書かれています。以前は各言語バージョンを手で書く必要がありました。記事が増えるとどうしても追いつかなくなりました。そこで自動翻訳のパイプラインを構築しました。中国語の記事をpushすると、数分以内に日本語と英語のバージョンが自動生成され、自動でデプロイされます。

## 全体の構造

```
中国語の記事をpush
  → GitHub Actions（translate-content）
    → Cloudflare Workers AI を呼び出す
      → 翻訳結果をgitに書き戻す
        → Netlify が自動でビルド・デプロイ
```

いくつかの重要な決定事項：

- **翻訳結果をgitに保存**し、Netlifyのビルド時に一時的に生成しない。翻訳結果はレビュー・ロールバック・手動修正が可能で、Netlifyのビルドは純粋な（常に完成したMarkdownを取得する）状態を保つ
- **Cloudflare Workers AI の無料枠を使用**（毎日10,000 neurons）。個人ブログの翻訳量はこれで十分すぎる
- **訪問者側は完全に静的**：API keyはGitHub Actionsのみにあり、フロントエンドには秘密鍵や追加リクエストが一切なく、あらゆるサードパーティスクリプトも読み込まない

## モデル選定

Workers AI の無料プランにはモデルのホワイトリストがあり、すべてのモデルが動作するわけではありません。いくつかのモデルをテストしました：

- GLM、DeepSeekシリーズ：無料プランでは利用不可（403エラー）、即座に除外
- `llama-3.3-70b`：利用可能だが、純テキストの翻訳では**文の一部が翻訳されない**（一部の中国語の原文が残る）、使用不可
- `qwen3-30b-a3b-fp8`：中国語→日本語の品質が最も良い、最終的にこれを選択

## 最大の落とし穴：MarkdownをJSONに詰め込まない

初版では手間を省くために、タイトル、要約、本文を1つのJSONにまとめ、モデルに翻訳して元の形式で返してもらいました。結果として、フィールドはすべて正常でしたが、本文内のリンクの構文が破損しました：

```
元ファイルの記述：      [Hugo](https://gohugo.io)
JSON形式での出力：   Hugo（https://gohugo.io）          ← リンクが死んで、単なるテキストに
純テキスト形式での出力：  [Hugo](https://gohugo.io)          ← 構文が元のまま残る
```

qwen3とllamaの両方でこの問題が発生しました——特定のモデルの問題ではなく、「MarkdownがJSON文字列に含まれる」形態そのものがモデルにとって不向きで、エスケープレベルが多すぎるからです。

**2段階の呼び出しに変更**：フィールド（タイトル/要約/分類/タグ）は短いテキストで、小規模なJSON呼び出しで問題なく処理可能。本文は別途純テキストの呼び出しを行います。これにより、リンク、リスト、コードブロックがすべて元のまま残るようになりました。

## インクリメンタル：source_hash

すべての記事を毎回再翻訳するわけにはいかない——エディションの消費が増えるだけでなく、手動で校正した翻訳を上書きしてしまう可能性もある。そのため、各翻訳ファイルのfront matterに`source_hash`を保存します：

```toml
lang = 'ja'
title = '（翻訳後のタイトル）'
date = '2025-11-26'
draft = false
source_hash = '4bae5986e7a0…'  # 中国語の元ファイルのsha256、ヒントのバージョン番号とモデル名を含む
```

ルール：

- hashが一致 → スキップ、**API呼び出し0回**
- 中国語の原文が変更 → hashが一致しない → 自動で再翻訳
- モデルを変更 → hash内のモデル名が変更 → 全量再翻訳

## 人工保護ルール

- `source_hash`がない翻訳ファイル = 人工で書いたもの、スクリプトは**絶対に触らない**（上書きも削除もしない）
- 機械翻訳ファイルが人工で校正された後、中国語の原文が変更されなければ、再翻訳で上書きされない
- 1つの記事を翻訳したくない：中国語のfront matterに`auto_translate = false`を追加
- 中国語の元ファイルが下書きになる → 翻訳ファイルも同期して下架される；中国語の元ファイルが削除 → 翻訳ファイルが自動で削除される

機械翻訳ファイルの先頭には1行の引用ブロックの声明があり、元の中国語のリンクが記載されており、読者に中国語の原文を基準としていることを伝えています。
