エディタを開いて Markdown を手で書いて、git commit する必要はありません。

GitHub を AI に接続して、自然な言葉で書きたい内容を伝えるだけで、AI がリポジトリを読み、記事を生成し、コミットまで行います。

この記事は、その流れで書かれました。

## 準備

1. GitHub リポジトリがある（例：`myblog`）
2. AI の対話画面で GitHub アカウントを接続
3. AI にリポジトリの読み書き権限があることを確認

## 実際の流れ

### 1. まず AI にリポジトリを読ませる
こう言います：

> github の myblog リポジトリを読める？

AI は自動で：
- あなたの GitHub アカウントを確認
- リポジトリを検索
- ファイル構成を取得
- `hugo.toml` や既存の記事を読み込みます

### 2. 書きたい内容を伝える
例：

> 2本目の記事を書いて。テーマ：AIを使ってブログを更新する方法。あなたの今の仕事の流れをベースに。簡单にわかりやすく、三言語版で

### 3. AI が生成して提出
AI はリポジトリの構成に合わせて：
- `content/zh/posts/...`
- `content/ja/posts/...`
- `content/en/posts/...`

を作成し、`master` ブランチに一括コミットします。

提出後、Netlify などの CI が自動でビルド・デプロイします。

## ヒント

- 自然な言葉で指示するほど、望むスタイルに近くなります
- 三言語、カバー画像、日付なども指定可能
- 既存の記事を修正したい場合も同じ流れ：読ませてから修正内容を伝える
- コミット前に内容を確認したい場合は、そう伝えられば大丈夫です

## まとめ

GitHub を接続 → 自然言葉で指示 → AI が読み取り + 記事作成 + 提出。

あなたは内容を考え、AI が実装します。
