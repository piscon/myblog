## 摘要

大语言模型在**机器翻译**任务上已逼近实用阈值，但当输入是 Markdown 技术文档时，失败模式从「译得不好」转为「结构被破坏」：链接目标被改写、列表标记被吞入锚文本、代码围栏被吞并。这类损伤不会触发语法错误，却会让页面静默失真。本文将此类问题形式化为**字符空间冲突**问题：自然语言的译文空间与机器语法的标记空间共享同一字符流，模型无法可靠区分二者[^1]。

## 1. 研究背景

> 可靠性工程的一个基本结论是：不应要求组件「不犯某类错误」，而应让它**没有机会**犯该类错误。——引自 *Co-op Translator* 生产事故复盘

早期方案依赖提示词约束，典型规则如下：

- 「保持 Markdown 结构不变」
- 「只翻译链接文字，URL 原样」
- 「列表标记只能出现在行首」

实测表明这些约束**不可靠**：模型在 `1. *感谢 [Hugo](https://gohugo.io) 提供代码支持*` 这类组合上会稳定地产出 `[1. *Hugo](https://gohugo.io)に…`，即把有序列表标记与斜体星号整体吞入链接文字。值得注意的是，链接数量、标题层级、围栏计数全部守恒，因此基于计数的 QA 门会**静默放行**。早期曾把该结论表述为「纯提示词足够」，现已~~推翻~~修正[^2]。

## 2. 方法：占位符原子化

核心思想是把文档切分为两类区域：

| 区域类型 | 示例 | 处理方式 | 是否进入模型 |
|---|---|---|---|
| 机器语法 | `[text](url)` 的 URL 部分 | 原子化替换 | 否 |
| 骨架标记 | `1. `、`## `、`\|` | 成对保护 | 否 |
| 自然语言 | 正文段落、链接文字 | 保留 | 是 |
| 代码块 | 围栏内全部内容 | 整块替换 | 否 |

具体实现见下方伪代码（行内 `protectBody()` 与 `restoreBody()` 构成闭环）：

```python
def translate(body: str, lang: str) -> str:
    """保护 → 翻译 → 完整性门 → 还原"""
    protected, tokens = protect(body)   # «0» «1» …
    raw = model(protected, lang)        # 模型只见散文
    assert all(t.count == 1 for t in tokens)  # 完整性门
    assert skeleton_at_edges(raw)             # 位置门
    return restore(raw, tokens)               # 机械拼装
```

完整性门检查三件事：每个 token **恰好一次**、骨架 `lead`/`tail` 必须贴行首/行尾、还原后结构计数守恒。任何一项失败即重试，仍失败则该篇不落盘、旧译文原地保留。

## 3. 实验设置

验证分两层，且第二层不依赖外部服务：

- [x] 离线自测：全语料恒等往返 + 旧事故等价攻击拦截
- [x] 结构计数保险丝：链接、标题、围栏、列表项守恒
- [ ] 真实模型长文档压力测试（本文即为该层输入）
- [ ] 跨语言渲染一致性比对

其中「旧事故等价攻击」指人为构造如下损伤并验证门能拦下：

1. `lead` 标记被挪进句子中间
2. 收尾星号被移到行中
3. token 被删除、重复或伪造越界编号
   - 删除与重复触发完整性门
   - 伪造越界编号直接拒绝

## 4. 讨论

### 4.1 为什么不使用双通道互证

两次独立调用能降低随机损伤，但对**系统性错误**无效：同一模型面对同一组合结构会稳定地犯同一个错，比对结果一致、照样放行。这与「**稳定性大于省 token**」的约束并不矛盾——瓶颈是架构而非预算。

### 4.2 边界条件

正文若含字面量 `«1»`（书名号、法文引号或随手输入），会被 token 正则误认成占位符，导致越界与永久失败。修法是把 `«n»` 字面量与孤立 `«`/`»` **一并原子化**，使模型输入中唯一的 `«n»` 都是真编号。这提示一个更一般的原则：占位符字符集必须与自然语言字符集**完全隔离**，或由保护 pass 保证其唯一性，而不能仅靠「选个罕见字符」的赌注。

### 4.3 与内容管理系统的关系

输入边界（CMS 的富文本编辑器）只需输出普通 Markdown；保护层位于流水线内部，不新增 front matter 字段、不改动 schema。历史上 CMS 往返对 `*斜体* [链接](url)` 结构保真，因此输入端无需调整。

## 5. 结论

把可靠性从「模型是否听话」迁移到「模型根本接触不到语法」，可将链接打散与标记吞入两类事故从**概率事件**降为**架构上不可能事件**。代价是保护 pass 约百行代码与一次全量重译（提示词版本失配）；收益是提示词可以极简，且失败时旧内容原地保留，线上永不出现损坏页面。
